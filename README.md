# Football Stats

A football statistics web application built with Python, Flask, SQLite, HTML, CSS, and JavaScript.

> This project is currently under development.

## Planned Features

The application will retrieve football data from an external API, store relevant data locally, and provide a web interface for exploring football statistics.

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Local Setup

Clone the repository:

```bash
git clone git@github.com:YOUR_USERNAME/football-stats.git
cd football-stats
```

Create a virtual environment:

```bash
python3 -m venv .football-stats-venv
```

Activate the virtual environment on Linux/macOS:

```bash
source .football-stats-venv/bin/activate
```

Install the project dependencies:

```bash
pip install -r requirements.txt
```
